## Implemented scope

0.4-C1/C2/D/E now have shared Contracts/Core library and chain services, exact-byte JSON import/export with conflict rejection and tombstones, frozen single-card verification, ordered independent chains, continued child diagnostics, conservative summaries and CLI/UI entrypoints. Existing config/rules/analysis/comparison schemas and composed verify semantics remain compatible. Reports/downloads use frozen current-job evidence; running or failed jobs do not expose a terminal report as current. Locale does not change policy content or report bytes.

The workbench has separate Target configuration, Rulesets, Chains, Results and History surfaces. Primary card actions are visible without expanding long details. Child status, source binding and missing/coverage warnings remain visible; rule/finding lists expand on demand. English/Chinese strings and accessibility labels are localized; generated product text and current guidance are English. Confirmation uses a page dialog with visible scope and Cancel focus, avoiding the native confirmation bridge that blocked the first synthetic deletion test.
