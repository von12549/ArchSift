# 0.8 第四阶段机器恢复、归档与保留资格

2026-10-13。**机器支持范围通过，正式候选与独立人工仍待第五阶段。** 本记录只覆盖 Windows x64、SDK 风格 C# 合成外置构建和只读历史报告副本；不把旧 IFX 报告当作当前源码证明，也没有清理真实 IFX 证据。

失败或重启后的任务按持久 `job.json` 显示记录阶段、当前源码/外部输入差异和未知终态；恢复不会自动重启或声称当前验证。复用已 seal 运行会重新执行完整独立 validate 并另存回执，源或材料变化不能沿用旧成功。UI 区分取消请求与已取消；owned Windows Job Object 回收、文本部分日志和历史终态继续沿用第二阶段机器门禁。Seal 的取消令牌已传入源码发现、审查材料哈希和最终 Existing 验证，在发布 manifest 前再检查；预先取消不会产出成功文件。

归档预览列出整套运行文件、字节数和 SHA-256，create-new 复制后逐文件复核，保留原运行；封存绝对引用没有被改写，副本不冒称可直接 validate。清理仅接受已归档运行的精确 owned 文件清单：重新扫描用户指定的引用目录和当前报告目录、重新核对原件/归档哈希及保护路径。活动/未知终态、缺失归档、坏 JSON/不可用引用目录、实际引用、原始 binlog 均阻断清理。写入归档中的清理意图后才逐文件删除，再写完成回执；发生中断时意图标示可能部分完成，归档仍可恢复。未知文件和全部目录保留，不递归删除运行根。合成测试验证预览后新增引用会阻断、未知 `user-note.txt` 保留、已确认的 owned 文件可在归档核验后清理。真实证据没有执行清理。

新 EvidenceJob 不生成原始 `.binlog`。一旦运行中出现原始 binlog，普通归档/清理拒绝，保留为本机机密材料待单独私有审查；Web 文本材料预览有 256 KiB 截断，二进制不导出。保存的文本日志按环境赋值、敏感键行和已知敏感环境值脱敏，审查材料 SHA-256 绑定保存后的字节；这不证明任意自定义任务输出不含秘密。公开分发前仍须检查实际运行材料，原始命令输出未被声称可公开。哈希计量只覆盖 `AssemblyArtifacts.FileHash`，不覆盖 InputCapture 和 SDK 子进程 I/O，阶段耗时可重叠，不能相加；最终合成 UI 运行记录 12,672 次读取、1,627,167,248 bytes、1,070 ms 哈希时间。未以 mtime 缓存或省略最终逐字节校验换取速度。
