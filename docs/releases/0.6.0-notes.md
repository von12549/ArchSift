ArchSift 0.6.0 adds current-version display, live chain stages and per-ruleset progress, and configurable concurrency from 1 to 4 with serial execution as the default. Its launcher supports one Setup-managed configuration and multiple external profiles. The catalog and selection stay under `config`; Setup protection covers the managed configuration and library, while external profiles remain outside that protection.

The replacement candidate fixes two findings from the first human review. The workbench profile area is compact while retaining the identity, full path, protection status and export control. A new external profile starts with an editable JSON template copied from the validated managed configuration; the suggested `config/external.json` is created only after review and confirmation.

The independently downloaded ZIP and Setup assets passed 17 and 13 native checks, respectively. Real IFX serial, CLI and Web measurements met the frozen budget; an isolated old-installation copy completed 0.5→0.6→0.5 upgrade and rollback. An independent operator answered yes to eight UI and hands-on checks with confidence 5/5 and clarified that an L1 severity selection was a mistake; no issue was observed. The post-human read-only machine audit found the candidate assets, new installation, IFX target, original installation and host state unchanged.
