ArchSift 0.5.0 is accepted with the limitations below. The Windows x64 self-contained package adds a separate portable Setup executable with reviewed install plans, explicit 0.4.0 package adoption, byte-preserving backups, side-by-side upgrade, receipt rollback and journal recovery. The standard CLI now displays UI URL/PID/waiting output, bounds startup and stops its owned Web process on Safe shutdown, Ctrl+C or parent exit.

The exact product source is `c4010d8c45eecadb3c51272334ceb4169e27b6ce`. Windows and Ubuntu CI each passed 179 tests. Two independent ZIP smokes passed 17 checks each, and two Setup smokes passed 13 each. Independently downloaded draft assets matched their hashes. Operator-driven real IFX checks passed for a new installation and private UI, visible CLI/redirected output and shutdown, and an external copy's 0.4.0 adoption, 0.5.0 upgrade and rollback. The final read-only audit found the original IFX source, 0.4.0 install/reports, new install, external copy, backup, and host state unchanged, with no recorded ArchSift process or listener remaining. No IFX analysis or target build was performed during these installation checks.

Verify the ZIP and Setup executable against `SHA256SUMS.txt` and `acceptance.json` before use. The ZIP contains a candidate-state manifest recording build time; the separate acceptance record contains the final decision. Setup `--notices` prints its license and third-party notices. See the [installation guide](https://github.com/von12549/ArchSift/blob/main/docs/installation.md), [setup guide](https://github.com/von12549/ArchSift/blob/main/docs/setup.md) and [final acceptance](https://github.com/von12549/ArchSift/blob/main/docs/acceptance/20261010-0.5-final-acceptance.md).

Limits: physical operation on a host without any .NET SDK/runtime was not certified; no minimum Windows version or ARM64, Linux self-contained/Web, publisher signature, schema migration or uninstall claim is made. IFX policy adoption, C/D/E and full-source protection remain outside this release. The 0.4.0 release and its evidence are unchanged.
