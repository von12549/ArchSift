# ArchSift 0.9.0-dev prerelease notes

This prerelease adds the lightweight architecture-test workbench. CLI/Web share a daily-gate service running original C# architecture tests and enabled JSON type-dependency parameterized cases in reviewed consumer test projects, producing authoritative JSON/HTML. Web shows provenance/coverage/not-included inventories; subset diagnostics find discovery UIDs by name. Results/history use global Results/History, with English/Chinese switching.

Fixed local-candidate offline Release build, old-product regression and test-adapter checks passed. Packaged Web ran the original 80+one JSON complete gate in an authorized external IFX copy, coverage complete/allow 0. The user independently confirmed UID lookup, locale switch, results/history layout, legacy analysis entry, narrow view/keyboard. See [machine evidence](../acceptance/20261016-lightweight-lt06-ui-revision.md), [human evidence](../acceptance/20261016-lightweight-lt06-human-ui-review.md) and [candidate usage/limitations](../lightweight-test-workbench-candidate.md).

Before publication, a recursive-file-watcher race that could miss a new source directory's first file was fixed. Updated-source Windows/Ubuntu CI, 18 native MTP tests and repackaged real IFX 80+1 complete gate passed. Web static files matched the human-reviewed payload individually. See [prerelease source regression](../acceptance/20261016-lightweight-lt06-release-regression.md).

This GitHub prerelease supplies tagged source archives only, without general Windows binaries/installers. The accepted framework-dependent payload was a local-review candidate; IFX project references/cache/case baselines/rule paths were tied to an authorized external worktree, not a cross-machine installer. The repository includes ArchSift.Testing source/IFX integration examples. Each target still needs independent review/configuration.

Daily allow covers original IFX-specific tests and explicitly enabled JSON tests only, not complete source-binding proof. Unmigrated Class A/disabled Class B remain not included; formal IFX policy had not been adopted at this stage. The prerelease changes neither original IFX checkout/install nor the existing full-evidence workflow.
