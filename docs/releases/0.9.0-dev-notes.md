# ArchSift 0.9.0-dev 预发布说明

此预发布加入轻量架构测试工作台。CLI 与 Web 共用日常门禁服务：在经审查接入的目标测试工程中运行原有 C# 架构测试及启用的 JSON `type-dependency` 参数化案例，并生成权威 JSON 与 HTML 报告。Web 可查看来源、覆盖和未纳入清单；局部诊断可按名称查找发现 UID，结果与历史接入全局 Results／History，支持中英文切换。

固定本地候选的离线 Release 构建、旧产品回归及测试适配层检查通过；在获授权的外置 IFX 副本上，封装 Web 的完整门禁运行原 80 项和 JSON 1 项，覆盖完整，结果 `allow/0`。用户独立确认 UID 查找、中英切换、结果／历史布局、旧分析入口与窄窗口／键盘操作。详情见[机器记录](../acceptance/20261016-lightweight-lt06-ui-revision.md)、[人工记录](../acceptance/20261016-lightweight-lt06-human-ui-review.md)和[候选使用／限制](../lightweight-test-workbench-candidate.md)。

本次 GitHub 预发布仅提供标签对应的源码归档，不附通用 Windows 二进制或安装器。已验收的框架依赖载荷是本机评审候选，其 IFX 测试项目引用、包缓存、案例基准和规则路径均与获授权的外置工作树绑定，不能直接当作跨机器安装包。仓库包含 `ArchSift.Testing` 源码及 IFX 接入样例；目标接入仍须独立审查和配置。

日常 `allow` 只覆盖原 IFX 专用测试及明确启用的 JSON 测试，不提供完整源码绑定证明。未迁入的 A 类与未启用的 B 类保持未纳入；IFX 正式政策尚未采纳。此预发布不改变原 IFX checkout／安装或既有完整取证流程。
