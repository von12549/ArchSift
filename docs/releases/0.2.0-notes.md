# ArchSift 0.2.0

Local .NET architecture/dependency analyzer, MIT licensed.

- Six rule types, declaration project graph, real ArchUnitNET assembly checks and loopback Workbench.
- Compare HEAD against final on-disk worktree state or two explicit local Git endpoints. No target checkout/fetch/write. Policy changes and incomparable coverage are separate.
- JSON/HTML/SARIF 2.1.0. Violations do not block by default; configuration/execution/inconclusive/cancelled states remain visible.
- Windows x64 self-contained CLI/UI ZIP. Linux CLI was actually built/tested offline. Analysis targets SDK-style C# net8/net9/net10.
- Optional CI artifact example and product Windows/Linux verification workflows.

Local Windows 109 and Linux 107 regressions passed. The Linux image lacked SDK 9, so Windows verified the two real net8/net9 builds. Windows ZIP declaration analysis needs no SDK; changes needs Git; isolated build needs target SDK/packs, defaults offline and is not a complete sandbox. JSON is authoritative; unmapped SARIF findings never invent source lines.
