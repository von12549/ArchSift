# ArchSift 0.2.0

本地 .NET 架构与依赖分析工具，MIT 许可。

- 六类规则、声明项目图、真实 ArchUnitNET 程序集检查、loopback 工作台。
- HEAD 对磁盘工作区最终状态或显式本地两端 Git 比较；不 checkout/fetch/写目标，规则变化与不可比覆盖单列。
- JSON/HTML/SARIF 2.1.0；默认违规不阻断，配置/执行/无法判定/取消状态清楚可见。
- Windows x64 自包含 CLI/UI ZIP；Linux CLI 已经实际离线编译和测试。源码目标为 SDK-style C# net8/net9/net10。
- 可选 CI artifact 样例，自身 Windows/Linux 验证工作流。

Windows 本地 109 项、Linux 107 项回归通过；Linux 镜像没有 SDK 9，net8/net9 两个真实构建样例由 Windows 验证。Windows ZIP 的声明分析无需 SDK；changes 需要 Git；isolated build 需要目标 SDK/packs，默认离线且不是完整沙箱。JSON 是权威；没有源码映射的 SARIF 结果不虚构行号。

最终发布提交 `528ebb1237256018e3ca556919d25908c9b5c92d` 的 [远程 CI](https://github.com/von12549/ArchSift/actions/runs/37511164383) 已在 Windows/Linux 各通过 109/109（78 unit、29 integration、2 architecture），含固定 SDK 9 的 net8/net9 真实编译。两次先前失败（SDK patch 身份与缺少固定 targeting packs）及 artifacts 保留，不改写历史。正式 ZIP SHA-256：`ee2d27b4d7689ce3eef75c0d3402c684ad1c9a8cb492ae7c8e915510038699d8`；acceptance.json 记录固定资产与门禁结果。

下载后校验 SHA256SUMS.txt。ZIP 内包含 CLI/Web、README、规则模板、schema、CI 样例、MIT LICENSE、第三方库与 runtime 完整 notices，以及源 commit/输入/逐文件哈希 manifest。manifest 的 candidate 是冻结打包时点状态，最终接受状态由固定 ZIP SHA-256 和发布验收记录确认，不改写已验证字节。

未包含 NuGet tool 分发、Linux Web UI、allowlist、传递包/版本范围、在线漏洞审计、fail-on 或强制 CI。W11 仅登记为后续候选，不在此版实现。
