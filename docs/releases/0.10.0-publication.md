## Contents and limits

The Windows ZIP includes matching English version notes, getting started, installation/Setup, project configuration/integration and usage guides, plus schemas and generic templates. Five product packages and a generic offline feed are separate attachments. Private IFX configuration and its full feed are excluded. See [getting started](../getting-started.md) and [project integration](../project-integration.md).

Setup, CLI and Web executables are **not Authenticode signed**. Windows x64 is the binary distribution; Linux source/CLI CI does not qualify Linux Web or ARM64, and no minimum-Windows certification is claimed. Target builds/tests still require their approved SDKs and dependencies. Framework-dependent .NET 10 consumers need a supported patched runtime, at least 10.0.13 at this release. The daily 493-case gate does not prove complete source-bound compiler evidence; 187 out-of-daily projection items remain unknown/not-run. Live IFX remains on its separately adopted combination, registry publication is excluded, and retired/deferred routes stay retired/deferred.

The tagged source and bundled documentation retain their dated preparation ledgers. Final `acceptance.json` binds acceptance to those immutable bytes; this subsequent publication record closes the public distribution checks. Documentation updates on main do not retag or rebuild the release. WB00-WB10 and G01-G15 are complete for the declared GitHub Release scope.
