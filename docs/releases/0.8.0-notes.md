ArchSift 0.8.0 adds a persistent CLI/UI History with actual run times, shared Chain totals, and a reviewed external-build evidence workflow in the loopback Web UI. The workflow previews and records inputs, builds in an external snapshot with offline restore, reviews actual materials, seals a manifest v3, independently validates it, and exports configuration/rules copies. Failed and cancelled attempts keep their history; archive and cleanup require an explicit reviewed plan.

Setup now supports reviewed `remove-version` and `uninstall` commands. Exact owned version payloads move to a same-volume recovery archive. Evidence, reports, project registration, History, configuration, and rules remain at their original paths. Removal rejects a selected or evidence-referenced version. This is recoverable retirement, not disk reclamation.
