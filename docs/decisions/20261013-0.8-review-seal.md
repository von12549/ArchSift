# 0.8 第三阶段：实际审查、封存与配置副本

2026-10-13。所有审批绑定实际source/snapshot、capture/template及材料路径/hash组成的ReviewScopeSha256；审批前完整字节复核，变化需重审。构建/求值全退出0、owned tree停止、host相等、owner全部完成且无机器unknowns才可进入review；模板剩余unknown只允许为“实际材料审查及因果关系审批待完成”，其他输入缺口不能由表单清空。

必须填reviewer、human/delegated-agent角色、授权依据、构建因果理由、生成/读取关系、imports/tasks风险及边界，明确Approve；没有自动/默认批准，不将机器用例身份说成真实人类。材料列表分页和最多256KiB文本预览有明确截断；路径/哈希绑定且仅owned run，binary不作Web导出或文本解码。实际审查仍须读完整材料，不能仅看template。

review-notes/review-v2/manifest create-new，不覆盖已封存材料；重复审批拒绝。封存继续现有Core v3/review v2，随后独立validate完整字节/闭包/源变化检查，只有SourceBound通过才validated。取消/失败保留已完成材料并返回真实阶段；host drift停止且覆盖成功返回，不能自动修复。sourceBound与coverageComplete不转换为完整架构/运行时合规。
