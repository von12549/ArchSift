# W07 本机工作台设计

日期：2026-10-06（Australia/Sydney）

使用 frontend-design 指导本轮本机 UI：设计面向 .NET 开发者的架构工作台，主要任务是选范围、理解声明图、审查规则和区分违规/无法判定。

色彩采用图纸蓝而非营销渐变：底 #eef3f6、墨 #1e3c50、交互 #276a8c、通过 #147264、无法判定 #94632e、违规 #a24140。标题 Bahnschrift + Microsoft YaHei，正文 Microsoft YaHei，路径/JSON 使用 Consolas；全部系统字体，不向外网取资源。

布局：
```text
品牌 / 本次运行状态
目标、产物、规则路径    项目关系与范围
规则集表单 / 例外       结果、覆盖、无法判断项
历史运行               报告与规则草稿导出
```

对照 brief 后去掉通用统计卡/营销 hero；以真实目标根、当前运行状态与项目关系为视觉中心。配置和规则编辑有明确边界，结果区不在运行失败后残留成功；旧记录单列历史。统一左对齐、紧凑类型层级、可见焦点、窄屏单列，无默认循环动效。交互文案使用“发现项目”“验证规则”“保存规则”“取消本次运行”，不要求用户理解 Worker/proof 生命周期。
