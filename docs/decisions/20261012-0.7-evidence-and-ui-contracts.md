Review is an external trust boundary; SHA-256 proves content identity, not authenticity of review.

It does not execute MSBuild evaluation; operator reviews evaluation/tracking completeness against hash-bound actual logs/materials. ## Create From

Existing unsaved protection precedes editing; cancel leaves draft unchanged; copy runs no analysis.
