1. Select actual target, entry, TFM and Configuration, then external reviewed evidence. Show Git state, project scope, protected source root, exact tool paths/hashes and existing evidence.
2. Select external evidence directory/local feed. Preview snapshot paths, actual restore/build arrays, child environment, import/task risks and NuGetAudit overrides. Start authorizes only that concrete scope.

5. Review actual causality/materials/unknowns. Reviewer enters identity, rationale, generated relationships, import/task risks and boundaries, explicitly approving review v2. Only authorized reviewers approve; delegated Agents disclose identity/authority, never impersonate user approval.
6. Core seals create-new, independently validates, and displays binding/owners/contexts/closure. Failed validation never offers current-evidence adoption.
7. Show config differences, default new external copy. Preserve original profile/rules/registry/entryIds/chains/reports/payloads. Original config changes or policy adoption are specific separate actions.
8. Verify rules; Chain displays five status counts/findings/entry completeness above expandable details. Evidence completeness stays separate from execution/compliance.
9. History opens current/prior results with real execution time/provenance. User provides final usability observations; never autofill human acceptance.
