# ArchSift 0.5.0 实施与发布计划

日期：2026-10-10（Australia/Sydney）。状态：**IN PROGRESS / NOT ACCEPTED / NOT RELEASED**。

用户已授权新分支 `codex/archsift-0.5.0` 中执行安装升级设计，版本固定为 0.5.0，并授权相应提交、推送、PR、合并、验证及发布。已有未提交安装文档随新分支保留。授权不改变真实 IFX 人工逐块操作、目标只读、宿主不变和历史证据冻结要求。

0.4.0 历史资产与验收保持原版本及原哈希；只更新当前产品指南和新版本记录。直接 Web 临时入口不作为 CLI 修复通过证据。Windows 最低版本和 ARM64 支持未确立，Linux 继续仅 CLI 核心回归。

延期：MSI、服务、PATH/shell 集成、SDK 安装、全局工具、IFX 策略采纳、C/D/E、完整 MSBuild 求值、传递/版本 NuGet 规则、强制 CI。新 schema 迁移仅在独立实现并验收后支持；未知 schema 一律拒绝。

详细要求来自 [安装升级设计](20261010-installation-upgrade-design.md)。每包完成后在本计划与主计划维护证据；每个 AI 提交保留人类主作者并附 Codex co-author trailer。
