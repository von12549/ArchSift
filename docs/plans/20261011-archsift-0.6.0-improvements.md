## Chain 执行与进度

- 在 UI 中呈现 chain 的实际阶段及每个 ruleset 条目的状态，例如等待、运行、完成、违规、部分完成、失败、跳过和取消。应显示已完成条目数，并区分执行完整性与策略合规性；无法可靠计算的百分比不得作为精确进度展示。
- 支持对相互独立的 ruleset 条目进行**有上限的并行验证**，同时保留现有按序执行的选择。项目发现、规则集字节与输入身份冻结，以及必要的构建证据应由同一次 chain 共享；各条目的结果和输出隔离。最终报告仍按 chain 定义的顺序排列，结果不能受完成先后影响。
- 并行设计须明确资源上限、取消、输入漂移、单条目失败及其余条目继续执行、历史任务恢复显示与报告落盘的语义。进度来自正在运行的 job，不得将旧报告或尚未完成的条目显示为本次成功。CLI 与 UI 应共享同一执行及汇总契约。
- **范围边界：本轮不做 GitHub Workflow 式依赖图、`needs` 条件或“某组完成后启动另一组”的编排。** 现有 chain 条目之间没有依赖关系；是否扩展 schema 留待另行提出需求。

## UI 产品版本

- 在 UI 的固定且易找到的位置显示当前运行中的 **ArchSift 产品版本**，例如 `ArchSift 0.6.0`。版本应取自当前运行程序的版本身份，不能从 ruleset、chain 的 policy version 或安装目录名称推断。
- 版本信息在初始页面、运行结果和历史结果之间应保持清晰：页面显示当前程序版本；若展示历史报告版本，应明确标为该报告的 `toolVersion`，避免与当前程序版本混淆。桌面、窄屏及支持的 UI 语言均需检查可读性。

## 启动器与配置 profile 选择

**0.5.0 现状与问题。** `archsift.exe ui --config <JSON>` 和 Web 均在工作台页面启动前加载配置；文件缺失、JSON 无效或路径不安全时，现有 UI 不会打开。Setup 的 `install.json` 仅记录一个 `ConfigPath` 和对应库路径，升级、备份与回退按这一份受管状态核对。因此，在现有工作台上直接增加 profile 下拉框，无法解决无配置时无法启动的问题；任意选择另一份 JSON 也不能自动获得 Setup 的备份/回退保护。

**拟议用户流程。** 提供独立于目标配置启动的本地启动器或引导页：读取已验证安装的当前选中版本，列出明确登记或由用户指定的配置文件；显示规范化完整路径、目标根/入口、输出与规则库目录、有效/缺失/无效状态及是否受安装器管理。存在同名或内容相同的多个副本时仍分别列出，不根据文件名、修改时间或历史选择默默替用户决定。无可用配置时允许定位现有 JSON，或在明确审阅目标和路径后创建新配置；不得写入 IFX 等目标仓库。选择后先作 schema、路径和版本兼容性校验，再启动本次工作台并自动打开带有私有会话令牌的本地地址。工作台始终显示当前 profile 的名称和完整路径。

**运行与切换边界。** 启动器应作为拥有 UI 子进程的父进程一直存活，并提供重新打开页面与安全关闭入口；关闭浏览器标签不等于关闭服务。不得把会话 URL/token 写入日志、快捷方式或 profile 登记。切换 profile 需要先处理当前运行任务、未保存的 UI 修改与服务退出，再启动新会话；不得让旧任务结果、规则库或配置状态进入新 profile。保持现有显式 `ui --config` CLI 入口可用。快捷方式可启动启动器，但不要求 PATH、Profile、环境变量、服务或开机自启改动。

**安装与升级设计门禁。** 0.6.0 正式设计须决定 profile 登记位置、显示名称/路径身份、默认项与最近一次选择的保存方式，并区分受管和外部配置。推荐将受管 profile 清单及其引用的配置/规则库纳入可审阅的安装状态与升级备份契约；若允许外部未受管 profile，启动器必须明确标注其升级/回退保护范围，不能暗示已受保护。需明确现有单 `ConfigPath` 的 0.5.0 安装如何兼容或迁移，以及多 profile 中某一文件丢失、冲突、被编辑或包含不兼容 schema 时，inspect、upgrade、rollback 和 UI 启动应如何处理。此契约冻结前不改变 Setup schema，也不承诺自动扫描或修复任意 JSON 副本。

## 后续设计与验收入口

实施前确定进度事件/API 契约及并发上限，评估四组 IFX A 类 rulesets 的实际耗时与收益。用合成 chain 验证状态转换、串行/并行结果一致性、取消、失败、输入漂移和报告顺序。启动器使用合成安装与配置覆盖零份/一份/多份/同名副本、缺失或损坏文件、无效路径、版本切换、配置切换与退出清理；分别核对受管/外部 profile 的升级备份语义和 0.5.0 安装兼容性。真实 IFX 集成继续按人工逐块操作及宿主安全规则验收。验收标准和发布日期在 0.6.0 正式计划中另行冻结。
